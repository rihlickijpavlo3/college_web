**Дисципліна:** WEB-програмування

**Технології:** HTML5, Git, GitHub, GitHub Pages  

---

## 1. Опис проєкту
Проєкт являє собою статичний багатосторінковий web-блог, присвячений трьом унікальним містам світу: Дрогобичу, Києву та Токіо.  
Сайт побудований з дотриманням принципів чистої семантичної верстки HTML5 (без використання CSS/JS відповідно до методичних вимог 1-ї роботи), організований у структурований Git-репозиторій та підготовлений до розгортання на GitHub Pages.

---

## 2. Структура проєкту
```text
my-best-cities/
├── index.html           # Головна сторінка з анонсом блогу та списком міст
├── city-drohobych.html  # Детальна сторінка про місто Дрогобич
├── city-kyiv.html       # Детальна сторінка про місто Київ
├── city-tokyo.html      # Детальна сторінка про місто Токіо
├── form.html            # Форма пропозиції міста з різними типами полів
├── README.md            # Документація проєкту
└── images/              # Графічні матеріали (векторні SVG панорами)
    ├── drohobych.svg
    ├── kyiv.svg
    └── tokyo.svg
```

---

## 3. Реалізовані вимоги та семантика
- **Семантична структура:** використано теги `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<figure>`, `<figcaption>`, `<footer>`.
- **Навігація:** наскрізне меню навігації на кожній сторінці, побудоване на основі списків `<ul>` та відносних URL-шляхів (`city-*.html`, `form.html`, `index.html`).
- **Графічні ресурси:** усі зображення розміщено в каталозі `images/`, використано інформативні атрибути `alt`.
- **HTML-форма (`form.html`):**
  - Елементи введення: `<input type="text">`, `<input type="email">`, `<input type="number">`, `<input type="radio">`, `<input type="checkbox">`.
  - Багаторядкове текстове поле: `<textarea>`.
  - Випадаючий список: `<select>` з `<option>`.
  - Кнопки керування: `<button type="submit">`, `<button type="reset">`.
  - Організація форми: використання `<fieldset>`, `<legend>` та сувора прив'язка `<label for="...">` до відповідних `id` полів.
  - Атрибути обов'язковості: `required` для ключових даних.

## 4. Інструкція з локального запуску та версіювання

### Локальний запуск
Відкрийте файл `index.html` у будь-якому браузері (Chrome, Firefox, Safari тощо).

### Команди Git для ініціалізації та фіксації змін
```bash
# 1. Ініціалізація локального репозиторію
git init

# 2. Додавання файлів до staging area
git add .

# 3. Створення першого коміту
git commit -m "Initial commit: create static blog structure, city pages and suggestion form"

# 4. Перейменування головної гілки в main (якщо потрібно)
git branch -M main

# 5. Підключення віддаленого GitHub репозиторію
git remote add origin https://github.com/<USERNAME>/my-best-cities.git

# 6. Відправка змін на GitHub
git push -u origin main
```

---

## 5. Публікація на GitHub Pages
1. Відкрийте репозиторій на GitHub.
2. Перейдіть у розділ **Settings** &rarr; **Pages**.
3. У випадаючому списку **Source** оберіть `Deploy from a branch`.
4. У полі **Branch** вкажіть гілку `main` та каталог `/(root)`.
5. Натисніть **Save**.
6. Сайт стане доступним за адресою: `https://<USERNAME>.github.io/my-best-cities/`.
